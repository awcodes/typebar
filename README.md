# Typebar

A mobile-friendly Markdown symbol row for Filament's native `MarkdownEditor`: tapping a key inserts that literal character at the cursor, like a keyboard accessory row.

## Installation

```bash
composer require awcodes/typebar
```

Then publish the config file, which holds the default key set. See [Installation](https://docs.aw.codes/typebar/0.x/installation) for that step.
